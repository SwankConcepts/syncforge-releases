# SyncForge™ — Windows releases

**SyncForge** is a Windows tray app that installs and updates World of Warcraft addons (Retail, Classic and Forever) and, with Pro, keeps your addons and their settings in sync across your PCs through your own cloud folder.

This repository contains **official release packages only** (installers and update packages attached to [Releases](https://github.com/SwankConcepts/syncforge-releases/releases)). It contains no source code.

## Install

1. Download **[SyncForgeApp-win-Setup.exe](https://github.com/SwankConcepts/syncforge-releases/releases/latest/download/SyncForgeApp-win-Setup.exe)** (latest release).
2. Run it. It installs for your Windows account only (no admin rights) and starts SyncForge.

Requires Windows 10 (1809+) or Windows 11, x64. Setup installs the .NET 10 Desktop Runtime if it's missing.

## Updates

Click **Check for updates** in SyncForge (top bar, or Settings → App updates). New versions download and install in one click. Your settings are kept.
